🟢 Sambung ke Google Sheets (Wajib Setup Sekali Sahaja)
Setelah setup, semua jawapan peserta akan terus masuk ke Google Sheets anda secara automatik — anda boleh tengok markah pada bila-bila masa tanpa peserta perlu buat apa-apa.

Langkah-langkah setup:
1️⃣ Pergi ke sheets.google.com → buat spreadsheet baru → namakan "Kuiz Tatakelola KKJ"
2️⃣ Dalam spreadsheet, klik menu Extensions → Apps Script
3️⃣ Padam semua kod sedia ada, kemudian tampal kod di bawah:
4️⃣ Klik Deploy → New deployment → Web app → set Execute as: Me, Who has access: Anyone → klik Deploy
5️⃣ Copy URL yang diberikan, tampal di bawah dan klik Simpan URL
